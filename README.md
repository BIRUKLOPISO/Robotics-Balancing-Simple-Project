# Robotics-Balancing-Simple-Project

This is a simple robotics simulation project created in **CoppeliaSim**. 

##  About the Project
This scene demonstrates the Balancing concept in robotics. It serves as a beginner-friendly example of how balancing works within the simulation. 

The scene includes :
*   Balancing
*   Movement of a balancer

##  How to Run
1. Download and install [CoppeliaSim](https://www.coppeliarobotics.com/) (the educational version is free).
2. Download the `2nd.ttt` file from this repository.
3. Open CoppeliaSim, go to **File → Open scene**, and select `2nd.ttt`.
4. Press the **Play** button (▶) at the top of the CoppeliaSim window to watch the movement.

##  File List
*   `2nd.ttt` - The main CoppeliaSim scene file containing the robot Balancing concept.
