# Robotics-Balancing-Simple-Project

A simple robotics project demonstrating **balance control** and **movement** of a robot while keeping itself balanced.

## About

This project shows how a robot maintains its balance while moving. The goal is to keep the robot upright and stable during motion using a basic balancing control approach.

## Features

- Keeps the robot balanced while standing
- Maintains balance during movement
- Simple, easy-to-understand implementation

## How It Works

The robot continuously checks its tilt/position and adjusts its movement to stay upright. When it starts to lean, it corrects itself to keep its balance while continuing to move.

## Getting Started

1. Download this repository.
2. Open the project files in Copela Sim.
3. Click run.
